# Security Policy

## Supported Versions
Die jeweils letzte veröffentlichte Version erhält Sicherheits-Updates.

## Reporting a Vulnerability
Sicherheitslücken bitte **nicht** öffentlich als Issue melden, sondern per E-Mail an
**you@example.com** (gerne PGP-verschlüsselt). Du bekommst zeitnah eine Rückmeldung
und wirst über den Fix-Verlauf auf dem Laufenden gehalten.
