# Letterhead — documentation

Organised after [Diátaxis](https://diataxis.fr/): learning, doing, looking up and understanding are four different needs, so they get different pages.

**New here?** → [Getting started](tutorial.md) — from an empty note to a finished PDF letter in five minutes.

**Something not working?** → [Troubleshooting](troubleshooting.md) — the exact message you see, what it means, what to do.

| | |
|---|---|
| **[Getting started](tutorial.md)** | Learning-oriented. Sender profile, letter frontmatter, preview, PDF export, folding. |
| **[Troubleshooting](troubleshooting.md)** | Task-oriented. "No recipient in the frontmatter", "Printing is not possible", an address that sits too high in the window. |
| **[Reference](reference/frontmatter.md)** | Information-oriented. [Frontmatter fields](reference/frontmatter.md) · [Settings](reference/settings.md) · [Theming / CSS tokens](reference/theming.md). |
| **[Explanation](explanation/din5008.md)** | Understanding-oriented. [Why the DIN 5008 measurements are what they are](explanation/din5008.md). |

Every page also exists in German (`*.de.md`, [Einstieg](tutorial.de.md)). The [README](https://github.com/johannes-kaindl/obsidian-letterhead/blob/main/README.md) covers what the plugin does and how to install it.
